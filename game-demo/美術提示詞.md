# ECHO 回聲：美術提示詞

生圖網站：https://perchance.org/ai-text-to-image-generator

## 使用方式

1. 打開網站，把下面的英文提示詞貼到 **Description**，再把「共用負面提示詞」貼到 **Negative prompt**（anti-description）。
2. **Art style** 建議選 `Cinematic` 或不選；**Shape** 依用途選（商店橫幅選 landscape，直式封面選 portrait）。
3. 每組多生成幾張，挑風格最一致的。
4. 存成下方表格的檔名，放進 `game-demo/art/` 資料夾，告訴我之後我會接進遊戲。

## 風格統一原則

遊戲本身是「全黑背景 + 發光線條 + 聲波圓環」的極簡風格，所以每張圖都在最後加上這段共用風格，讓所有圖片看起來像同一款遊戲：

**共用風格（接在每段提示詞最後）**

```
dark minimalist horror, pitch black background, thin glowing line art, concentric sound wave rings, volumetric haze, high contrast, cinematic lighting, large negative space, no text
```

**共用負面提示詞（Negative prompt）**

```
text, letters, watermark, logo, signature, gore, blood, child, baby, kid, nudity, cartoon, anime, bright daylight, cluttered, low quality
```

負面提示詞刻意排除了孩童。故事雖然和孩子有關，但畫面一律用「空搖籃、紅線、蠟封」等物件來暗示，不畫出受害的孩子。這樣做比較有恐怖的留白感，也能避開 Steam 審核和平台規範的問題。

## 上架前必須注意

- **Steam AI 內容揭露**：上架時要在 Steamworks 的 AI 揭露欄位，說明商店圖或遊戲內圖片是 AI 生成的。規則近年有調整，申報前請看當時的最新版本。
- **商用授權**：使用前請確認 perchance 生成圖片的商業使用條款，並保留生成紀錄（日期、提示詞、截圖）。
- **版權**：純 AI 生成的圖片，在多數地區可能無法取得版權保護，別人可以合法複製。Logo、主角等核心識別最好人工繪製，或在 AI 圖上大幅修改。
- **商店截圖必須是真實遊戲畫面**：AI 插圖只能用在膠囊圖、主視覺這類宣傳圖，Steam 的「螢幕截圖」欄位要放實際遊戲畫面。
