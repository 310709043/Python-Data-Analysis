# 肉繭修道院 COCOON ABBEY（暫停）

> 第三夜，院長把整座修道院縫成了一個繭。

**狀態：暫停。** 回聲病棟上架後再評估要不要做。在那之前不要碰它，新點子寫進 [`../../shared/ideas-inbox.md`](../../shared/ideas-inbox.md)，代號 `abbey`。

## 原型裡已經有的

- 3 名角色：艾格妮絲（搖鈴引開守衛）、褚屠夫（擊殺，留下屍體）、小縫（縫眼睛，不留屍體；能鑽通風口）
- 會被牆擋住的視野錐：近處誰都看得到，遠處看不到小縫；血肉草可以藏身
- 計畫模式：先替每個人排好一個動作，再同時執行
- 屍體被發現會觸發警報

## 為什麼暫停

每張地圖都要大量手工設計和反覆測試平衡，對個人開發者負擔最重。和回聲病棟的潛行機制有重疊，等做完回聲病棟、累積了潛行關卡設計的經驗，再回來評估會更準。

## 暫停前的想法

- 15 張地圖，5 名角色（之後加入「瘋修女」、「沒有皮的狗」）
- 修道院會隨劇情長大，重玩時路線改變
- 主線約 25 小時，加上挑戰徽章約 35 小時
