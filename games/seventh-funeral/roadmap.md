# 第七次葬禮：里程碑

分兩段。**副線期間（F1～F3）不寫正式程式**，等回聲病棟上架後才進入正式製作（P1 以後）。

## 副線期間（每週 1 天）

| 里程碑 | 時間 | 完成條件 |
|---|---|---|
| M0 網頁原型 | 2026-11 ✅ | 可玩的靈堂 ＋ 3 個區域 ＋ Boss ＋ 叫魂禁忌 |
| F1 設計定稿 | 2026-12 ～ 2027-03 | GDD 七個區域、七條禁忌、七位親族都寫完；故事大綱（七次死亡各揭露什麼）定稿 |
| F2 美術風格定稿 | 2027-04 ～ 2027-09 | 主角 ＋ 5 種敵人的像素動畫（待機、走路、攻擊、受傷、死亡）；1 張場景概念圖；色票 |
| F3 內容儲備 | 2027-10 ～ 2028-07 | 150 段對話初稿；3 首音樂主題；祭品、敵人數值表（試算表） |

> 如果回聲病棟的進度比預期慢，**F2、F3 也跟著延後**，不要拿主線的時間來補副線。

## 正式製作（回聲病棟上架後，約 2028-09 開始）

| 里程碑 | 預計時間 | 完成條件 |
|---|---|---|
| P1 戰鬥手感 | 2028-09 ～ 2028-11 | Godot 裡一個房間、3 種敵人，打起來比網頁原型更爽快；找 5 個人試玩 |
| P2 一輪循環 | 2028-12 ～ 2029-03 | 靈堂 → 區域 1（8 個房間）→ Boss → 死亡回靈堂，祭品系統可用 |
| P3 Steam 商店頁 | 2029-04 | 商店頁上線（因為已經有回聲病棟的經驗，會快很多） |
| P4 搶先體驗 | 2029-05 ～ 2029-10 | 區域 1～3 ＋ 3 個 Boss；上架搶先體驗 |
| P5 正式版 | 2030 | 7 個區域、真結局、頭七模式 |

## 為什麼考慮搶先體驗

Roguelike 很適合邊開發邊收集玩家回饋（Hades 也是先上搶先體驗）。區域可以一個一個加，平衡可以靠玩家數據調整，也比較早有收入。
