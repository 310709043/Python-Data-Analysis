## 一段話賣點

你是躺在棺材裡的阿生。村裡要替你辦七次葬禮，你卻一次又一次醒來，拿著哭喪棒走上出殯的路。紙紮人、殭屍、紙新娘擋在前面，戰鬥中還會有人喊你的名字，應了就回不去。每死一次，靈堂裡的金童玉女就離你更近一點，道士也會多說出一點真相：這七次葬禮，到底是辦給誰的？

## 現在（副線期間）只做這些

回聲病棟上架之前，第七次葬禮**不寫正式程式碼**。每週一天的時間只用在：

1. 劇本與世界觀（7 次葬禮、7 位親族、對話）
2. 民俗研究（喪葬流程、禁忌、紙紮工藝）
3. 像素美術（角色動畫、色票）
4. 音樂（嗩吶主題、京劇鑼鼓點、童謠）
5. 數值表（祭品、敵人、武器，用試算表）

這些工作完全不會跟回聲病棟搶程式時間，等到正式開工時，素材和設計都已經準備好了。

## 1.0 範圍鎖定

### 做

- [ ] 7 個區域，每區有一條**禁忌**規則
- [ ] 6 種喪葬武器，每種 3 種流派
- [ ] 60 種以上祭品
- [ ] 15 種以上敵人，7 個 Boss
- [ ] 7 位可以交談的親族，約 150 段對話
- [ ] 「頭七」高難度模式
- [ ] 繁體中文、簡體中文、英文

### 不做

- 多人連線
- 開放世界
- 角色配音（只做喊魂、戲腔這類氣氛人聲）
- 使用真實宮廟、神明名號或真實符令內容（避免爭議，見 GDD）
