# 共用技術筆記

兩款都用 **Godot 4**。這樣在回聲病棟學到的東西，可以直接用在第七次葬禮。下面整理三個網頁原型裡已經驗證過、之後會重複用到的技術。

## 後製（兩款都用）

原型的順序：場景渲染 → 光暈（Bloom）→ 自訂調色 shader。

調色 shader 依序做這些事：
1. 曝光
2. ACES 色調映射
3. 飽和度調整
4. 暗部、亮部分別上色（回聲病棟：冷青／暖黃；第七次葬禮：青綠／紅橘）
5. Gamma
6. 暗角
7. 狀態疊色（危險、受傷、禁忌）
8. 底片顆粒

Godot 對應：WorldEnvironment 的 Glow 和 Tonemap（ACES），其餘寫成一個全螢幕後製 shader。**做成可以共用的檔案**，兩款只要改參數。

## 程序合成音效（兩款都用）

原型裡所有聲音都是即時合成的，沒有用任何音檔：
- **殘響**：用衰減噪音產生的脈衝響應，接卷積器（ConvolverNode）
- **方向性**：立體聲左右平移（StereoPanner），隔牆時加低通濾波讓聲音變悶
- **人聲**（喊魂、聖歌、戲腔）：鋸齒波通過 2～3 個帶通濾波器（母音共振峰）＋ 顫音
- **打擊樂**（鑼、木魚、鈸）：幾個不成倍數的正弦波 ＋ 濾波噪音

正式版可以選擇：沿用合成（檔案小、有獨特感）或換成錄音素材（更真實）。也可以混用：環境音合成，人聲錄音。

## 尋路與視野（回聲病棟、肉繭修道院）

- 原型：網格 BFS 尋路 ＋ 「拉直路徑」（看得到的路點直接跳過）
- 視野：沿射線每 0.15 格取樣，碰到牆就停
- Godot 對應：NavigationAgent3D、RayCast3D

## 像素精靈放在 3D 場景（第七次葬禮）

- 像素圖用最近鄰取樣（Nearest），不要用 mipmap
- 精靈是 3D 平面，稍微往鏡頭傾斜約 15°，`alpha scissor` 讓它能投射正確的影子
- 程式自動加 1 像素深色外框
- 受擊閃白：調高自發光強度
- Godot 對應：Sprite3D（billboard 關掉，手動傾斜）＋ 自訂 shader 做閃白

## 移軸景深（第七次葬禮）

依照畫面垂直位置決定模糊量：中間清楚，上下模糊，用 16 點黃金角取樣。在 Godot 寫成後製 shader 的一部分。
