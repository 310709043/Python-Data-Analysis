# Steam 上架清單

兩款遊戲共用。第一次（回聲病棟）照著做，順便把實際踩到的坑補在最下面，第二次（第七次葬禮）就會快很多。

> 規格和規定會變，以 Steamworks 後台與官方文件的最新說明為準。

## 1. 註冊（M3 開始時）

- [ ] 註冊 Steamworks 合作夥伴帳號
- [ ] 填寫稅務資料、銀行帳戶（身分驗證需要幾天）
- [ ] 繳交上架費：**每款遊戲 US$100**（遊戲總收入達到 US$1,000 後會退回）
- [ ] 建立 App，記下 App ID

## 2. 商店頁

- [ ] 遊戲名稱（中英文）、簡短描述、詳細描述
- [ ] 標籤：例如 Horror、Stealth、Psychological Horror、Atmospheric
- [ ] 主要宣傳圖：橫幅、小型、主要、直式、遊戲庫封面與主視覺等多種尺寸（尺寸照後台列表做）
- [ ] 至少 5 張截圖（1920×1080）
- [ ] 預告片：前 5 秒就要看到核心玩法（回聲擴散的那一刻）
- [ ] 系統需求
- [ ] 成人內容問卷：如實填寫血腥、恐怖內容
- [ ] 支援語言

## 3. 「即將推出」頁面

- [ ] 送審（通常需要幾個工作天）
- [ ] 上線後開始累積願望清單
- [ ] 正式上架前，「即將推出」頁面**至少要先上線 2 週**

## 4. 試玩版與新品節（M4）

- [ ] 試玩版建立成獨立的 Demo App（在 Steamworks 後台從主遊戲建立）
- [ ] Steam 新品節每年約 2 月、6 月、10 月舉辦，**報名截止日比活動早 1～2 個月**，要提前查
- [ ] 新品節期間：直播試玩、回覆每一則討論

## 5. 正式上架（M7）

- [ ] 上傳正式版建置（SteamPipe）
- [ ] 建置送審
- [ ] 設定價格與首發折扣
- [ ] 成就、雲端存檔、Steam Deck 相容性
- [ ] 上架日按下「發佈」

## 宣傳時間線（建議）

| 時間 | 做什麼 |
|---|---|
| 商店頁上線當天 | 發預告片，到相關社群分享（巴哈姆特、PTT、Reddit r/HorrorGaming、X） |
| 每 2 週 | 一則開發進度（GIF 或短影片最有效） |
| 新品節前 1 個月 | 寄試玩版給恐怖遊戲實況主 |
| 上架前 1 週 | 預告片 2.0、寄正式版金鑰給媒體與實況主 |
