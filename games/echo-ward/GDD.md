# 回聲病棟：遊戲設計文件

狀態標記：✅ 網頁原型已做　🔲 規劃中

## 核心循環

```
在黑暗中移動 → 發出回聲取得視野 → 判斷守衛位置並繞過（或利用）
      ↑                                              ↓
  進入下一章 ← 開啟出口 ← 收集殘頁、拼湊真相 ←─────────┘
```

## 核心機制

| 機制 | 規則 | 狀態 |
|---|---|---|
| 回聲 | 按鍵發出；環狀波每秒擴散 13 格；照亮牆、揭露怪物 2.5 秒；冷卻 1.4 秒；**11 格內的盲眼修士會聽見** | ✅ |
| 移動 | 走路 2.3 格/秒（2.1 格內聽得到）；奔跑 4.2 格/秒（6 格內聽得到） | ✅ |
| 蠟燭 | 手上小範圍照明；盲眼修士靠近時會亂閃；隨機事件會讓它熄滅約 1 秒 | ✅ |
| 警覺條 | 被提燈修女看見時累積，滿了就被抓 | ✅ |
| 殘頁 | 撿到會暫停並顯示文字；集滿本章數量才會開出口 | ✅ |
| 回聲才看得到的東西 | 牆上的血字、會移位的幻影 | ✅ |
| 躲藏點 | 衣櫃、病床底下；躲進去時心跳聲會變大 | 🔲 |
| 丟東西製造聲音 | 丟玻璃瓶，把盲眼修士引開 | 🔲 |
| 存檔 | 每章開頭自動存檔 | 🔲 |

## 劇情骨架

- **背景**：聖艾格妮絲病棟收容「聽不見的孩子」。院長相信只要縫上第二雙耳朵，孩子就能聽見神的聲音。
- **主角**：手術後醒來的病人。主角學會用回聲看世界，這正是院長想要的結果。
- **回聲之子**：之前手術失敗的孩子們，只剩下模仿聲音的本能。
- **殘頁來源**：修女日誌、病歷、孩子的塗鴉、院長的講道稿。
- **三種結局**：
  - **A 逃出**：從井口爬出去，外面是另一間一模一樣的病棟（暗示循環）。
  - **B 縫合**：把院長的耳朵縫起來，讓他再也聽不見。
  - **C 留下**：放棄逃走，成為新的回聲之子。需要集滿所有殘頁。

## 美術方向

- 低多邊形模型加上程序或手繪貼圖。黑暗會蓋住大部分細節，所以**把預算花在燈光上**。
- 後製效果：光暈、ACES 色調映射、底片顆粒、暗角、色差（危險時增強）。原型裡已經有完整的設定可以參考。
- 色彩：暗部偏冷青，蠟燭偏暖黃，回聲是冰藍，危險是血紅。

## 音效方向

- 戴耳機玩是體驗的一半。所有守衛都要有**方向性的聲音**：修女唱聖歌，修士喘氣，孩子咯咯笑。
- 空間殘響、會隨危險加速的心跳、隨機的遠處異響。
- 原型的聲音都是即時合成的。正式版可以保留合成的方式，或者換成錄音素材。

## 從網頁原型移植到 Godot

| 原型（three.js） | Godot 4 |
|---|---|
| 地圖字串陣列 | GridMap 或 TileMap 3D，用關卡編輯器擺放 |
| 手寫 BFS 尋路 | NavigationRegion3D + NavigationAgent3D |
| 視野判斷（網格取樣） | RayCast3D／PhysicsDirectSpaceState3D |
| EffectComposer 後製 | WorldEnvironment（Glow、Tonemap ACES）＋ 自訂後製 shader |
| Web Audio 合成音效 | AudioStreamGenerator 或預錄音檔 ＋ AudioStreamPlayer3D |
| 回聲揭露效果 | 隨時間擴大半徑的 OmniLight3D ＋ shader 中的 uniform |
