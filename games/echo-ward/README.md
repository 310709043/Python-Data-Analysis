## 一段話賣點

你是被縫上第二雙耳朵的病人。病棟裡沒有光，你得發出回聲才看得見牆、怪物和牆上的血字。但聲音會引來盲眼修士，回聲裡也會照出不該存在的人影。每一次按下回聲鍵，都是一次賭博。

## 1.0 範圍鎖定

### 做

- [ ] 12 章、3 層樓（B1 縫合室 → 1F 病房 → 2F 院長室）
- [ ] 6 種守衛（已做 3 種，見 [GDD](GDD.md#守衛)）
- [ ] 約 220 張殘頁，拼出完整故事
- [ ] 3 種結局
- [ ] 二周目「全黑模式」：沒有蠟燭，只能靠回聲
- [ ] 繁體中文、簡體中文、英文
- [ ] 存檔：每章開頭自動存檔
- [ ] 手把支援（Steam Deck 可玩）

### 不做（1.0 之後再說，或永遠不做）

- 戰鬥系統（玩家永遠不能攻擊，這是核心）
- 程序生成地圖（每一章都手工設計）
- 多人連線
- 角色配音（用文字和環境音說故事）
- 開放世界、自由探索的大地圖

### 保底線

如果到 M4 進度落後超過 2 個月：**1.0 先上 8 章（約 20 小時）**，第 9～12 章做成免費更新。這條線現在就定好，到時候不用再糾結。
