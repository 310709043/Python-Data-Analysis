# 回聲病棟：里程碑

假設每週約 20 小時。每個里程碑都要**全部完成條件打勾**，才能進入下一個。

| 里程碑 | 時間 | 狀態 |
|---|---|---|
| M0 網頁原型 | 2026-11 | ✅ 完成 |
| M1 Godot 灰盒第一章 | 2026-12 ～ 2027-01 | ⏳ 下一個 |
| M2 垂直切片 | 2027-02 ～ 2027-03 | |
| M3 Steam 商店頁上線 | 2027-04 | |
| M4 試玩版與新品節 | 2027-05 ～ 2027-10 | |
| M5 內容完成 | 2027-11 ～ 2028-05 | |
| M6 測試與打磨 | 2028-06 ～ 2028-07 | |

## M0 網頁原型 ✅

- [x] 回聲機制可玩
- [x] 3 種守衛（提燈修女、盲眼修士、回聲之子）
- [x] 環境音、心跳、方向性聲音
- [x] 3 張殘頁與一個出口

## M1 Godot 灰盒第一章

目標：學會 Godot，並且用**方塊和膠囊**把原型的第一章完整重做一次。這個階段不做美術。

- [ ] 從開始到結束可以玩完第一章（不會卡死、不會穿牆）
- [ ] 回聲、走跑噪音、3 種守衛的行為和原型一致
- [ ] 被抓會重來，拿滿殘頁會開出口
- [ ] 至少 3 個人試玩過，回饋記在 devlog

## M2 垂直切片

目標：第一章達到「可以放進預告片」的品質。

- [ ] 第一章正式美術（牆面、地板、道具、角色）
- [ ] 後製、燈光、聲音達到原型以上的水準
- [ ] 主選單、設定（音量、畫質、按鍵）、暫停選單
- [ ] 存檔與讀檔
- [ ] 能錄出一段 60 秒、你願意放上 Steam 的遊玩影片

## M3 Steam 商店頁上線

詳細步驟見 [`../shared/steam-checklist.md`](../shared/steam-checklist.md)。

- [ ] Steamworks 註冊，繳交上架費 US$100
- [ ] 商店頁圖片、5 張以上截圖、預告片
- [ ] 「即將推出」頁面通過審核並上線
- [ ] 開始每 2 週發一則開發進度（X／Threads／Bilibili／巴哈姆特，挑 1～2 個就好）

## M4 試玩版與新品節

- [ ] 第 2～4 章完成（灰盒 → 正式美術）
- [ ] 試玩版 = 第 1～2 章，約 40 分鐘
- [ ] 報名並參加 Steam 新品節（每年 2 月、6 月、10 月舉辦，報名截止日比活動早很多，要提前查）
- [ ] 至少 10 位陌生人試玩，整理回饋
- [ ] **保底線檢查**：如果進度落後超過 2 個月，啟動「1.0 先上 8 章」方案（見 README）

## M5 內容完成

- [ ] 第 5～12 章全部完成
- [ ] 220 張殘頁全部寫完並放進遊戲
- [ ] 3 種結局
- [ ] 二周目全黑模式

## M6 測試與打磨

- [ ] 封閉測試（Steam Playtest 或發金鑰）
- [ ] 簡中、英文翻譯
- [ ] 手把支援、Steam Deck 測試
- [ ] Steam 成就（約 20～30 個）
- [ ] 效能：中階顯卡 1080p 穩定 60 FPS

## M7 正式上架

- [ ] 設定上架日（「即將推出」頁面至少要先上線 2 週）
- [ ] 上架前一週：預告片 2.0、媒體與實況主寄送金鑰
- [ ] 上架後 2 週內：每天看評論，修重大錯誤

## 誠實提醒

一個人、業餘時間、第一款遊戲，做出 30 小時的內容是很有野心的目標。最常見的失敗原因不是技術，而是**範圍不斷變大**和**中途跑去做新的遊戲**。所以才有 README 裡的範圍鎖定和保底線，以及總部的「一次只有一款主線」規則。
