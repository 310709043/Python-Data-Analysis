## 重新渲染

```bash
cd myvoca-video
npm install
npm run render   # 輸出 out/myvoca-intro.mp4
```

瀏覽器執行檔路徑設定在 `remotion.config.ts`(目前指向容器內建 Chromium,
在本機開發時請改成本機 Chrome 路徑或直接移除該行讓 Remotion 自行下載)。
