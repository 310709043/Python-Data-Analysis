## 技術說明

- **架構**：單一持續的 Three.js 粒子宇宙（`@remotion/three`），約 2600 顆粒子的
  目標位置與顏色在七幕之間連續變形；所有「轉場」都由攝影機運動完成，
  場景本身從不切換或重新掛載。文字為 HTML 疊層合成，避免 WebGL 內載入
  中文字型的風險。
- **後製**：Bloom 光暈 + Vignette 暗角（在本容器的軟體算圖環境下保留電影感
  的主要來源）。景深模糊（DepthOfField）因軟體算圖成本過高而未啟用——這是
  在無實體 GPU 的環境中為了合理算圖時間所做的取捨。
- **輸出**：1920×1080 / 30fps。同一份 Scene 元件以「秒」為單位撰寫，
  未來若要 4K/60fps 正式輸出，只需調整 composition 尺寸即可，視覺邏輯不變。

## 重新渲染

```bash
cd myvoca-video
npm install
npm run render   # 輸出 out/myvoca-intro.mp4
```

瀏覽器執行檔路徑設定在 `remotion.config.ts`（目前指向容器內建 Chromium，
在本機開發時請改成本機 Chrome 路徑或直接移除該行讓 Remotion 自行下載）。
