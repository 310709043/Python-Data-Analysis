# MyVoca 3 分鐘正式講稿 — Plan A / Plan B 兩版

**目標聽眾**：各產業企業主 / 高階決策者（電信、金融、零售）
**核心目標**：讓長官帶走三句話，並感受到「這是營收工具，不是客服工具」
**語速設計**：以每分鐘約 240 字的舞台語速估算；**粗體**＝放慢、加重；`—`＝停頓一拍。

## 全場要帶走的三句話（結尾重申）

1. **不是每個產業需要不同的 AI，而是同一套企業 AI** — 懂你的知識、懂你的流程、更懂你的客戶
2. **不只接住客戶，而是聽出購買意願**
3. **不只是回答問題，而是推薦下一個最適合的方案**

### 2:20 – 2:45｜跨產業
